# Convention dashboard

Đọc và tuân thủ [AGENTS chung](../firmware/AGENTS.md) cùng [quy trình phát triển](../firmware/docs/techs/development.md). Task/report/checklist/techs dùng nguồn chung tại firmware; không sao chép thành bộ quy tắc riêng.

Dashboard dùng HTML/CSS/JS ES modules và VS Code Live Server, không framework hoặc bước build. Đọc README, design-system/MASTER.md và firmware/docs/techs/dashboard.md trước khi sửa UI. Giữ tên MQTT/HTTP theo hợp đồng; định danh JavaScript camelCase/PascalCase, hằng UPPER_SNAKE_CASE, thụt2 dấu cách. Không đưa fixture vào đường chạy live hoặc tự chạy task kế tiếp.
